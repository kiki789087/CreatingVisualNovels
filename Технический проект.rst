Технический проект
Разрабатываемая система реализуется на языке Python с использованием библиотеки PyQt6.


Архитектура программной системы
Программный продукт построен по принципу разделения данных и пользовательского интерфейса.

Система состоит из следующих программных модулей:
1) models/ - модель данных, которая реализует базовуб предметную область приложения без привязки к графическому интерфейсу:
    - класс Frame - описывает структуру данный отдельного кадра
    - класс Character - описывает структуру данных персонажа
    - класс Project - отвечает за управление списком кадров, операциями добавления, удаления, переименовывания и автоматической нумерации.
    - класс TextStyle - описывает оформление текстового поля: шрифт, цвета, координаты.
2) editor/ - модуль пользовательского интерфейса
    -класс EditorWindow - реализует главное окно, связывает элементы интерфейса с данными проекта, управляет состоянием элементов управления и навигацией.
3) widgets/ - модуль графических компонентов
    - класс SceneView - виджет для визуализации сцены. Обеспечивает послойную отрисовку, обработку событий мыши для перемещения персонажа.
    - класс Tool - задает режимы работы интерфейсных инструментов (режим перемещения).
4)  player/ - модуль режима воспроизведения
    - класс PlayerWindow - отвечает за запуск полноэкранного режима демонстрации проекта и последовательную смену кадров по событиям.

Описание структур и форматов данных:

1) Логические структуры данных
Для представления предметной области в программном продукте используется объектно-ориентированный подход. Модели данный не зависят от графического интерфейса пользователя и разделены на три основные модели:
    1. Модель данных кадра
    Каждый кадр новеллы описывается объектом класса Frame.
    Описание полей:
        - title (str) — название кадра, отображаемое в интерфейсе редактора и в списке кадров.
        - content (str) — текстовое содержимое (реплики, описание сценария), привязанное к кадру.
        - speaker (str) - имя говорящего персонажа.
        - text_visible (bool) - флаг видимости текстового слоя на сцене.
        - background_path (str) — путь к графическому файлу фонового изображения текущего кадра.
        - character (Character | None) — вложенный объект персонажа на кадре. Если персонаж отсутствует, значение равно None.
        - text_style (TextStyle) - объект, описывающий оформление текстового поля.
        - auto_title (bool) — флаг автоматического наименования. Если True, название кадра генерируется системой автоматически («Кадр N») при перенумерации. При ручном изменении пользователем устанавливается в False

    2. Модель данных персонажа
    Описывает параметры графического изображения персонажа, отображаемого на сцене.
    Описание полей:
        - name (str) — имя персонажа (текстовое поле, по умолчанию пустое).
        - image_path (str) —  путь к файлу изображения персонажа на диске.
        - x (float) — горизонтальная координата точки привязки персонажа на сцене.
        - y (float) —  вертикальная координата точки привязки персонажа на сцене.

    3. Модель данных проекта
    Проект визуальной новеллы представляет собой упорядоченный линейный список кадров и операции над ними.
    Описание полей:
        - frames (list[Frame]) — упорядоченный список объектов кадра (Frame), представляющий линейную последовательность сцен новеллы.
    Основные методы управления структурами данных:
        - add_frame() -> int — создает новый экземпляр Frame и добавляет его в конец списка frames. При наличии предыдущего кадра автоматически копирует значение поля background_path. Запускает автоматическую перенумерацию и возвращает индекс созданного элемента.
        - remove_frame(index: int) — удаляет элемент по индексу из списка frames с последующим автоматическим пересчетом названий оставшихся элементов.
        - rename_frame(index: int, text: str) — присваивает кадру пользовательское название и сбрасывает флаг auto_title в значение False. При передаче пустой строки восстанавливает автонумерацию (auto_title = True).
        - _renumber() — метод итерации по списку frames, присваивающий строковое значение f"Кадр {number}" всем кадрам с установленным флагом auto_title == True.

    4. Модель данных текста
    Описывает оформление текстового поля, отображаемого на сцене.
        - x, y (float) - положение левого верхнего угла текстового окна относительно фона.
        - width, height (float) - ширина и высота текстового окна относительно фона.
        - font_family (str) - название семейства шрифта.
        -  font_size (int) - размер шрифта в пикселях.
        - text_color (str) - цвет основного текста.
        - name_color (str) - цвет имени персонажа.
        - bg_color (str) - цвет фона текстового окна.
        - bg_opacity (float) - прозрачность фона текстового окна
        -  name_box_offset_x (float) - горизонтальный сдвиг поля имени персонажа относительно левого края текстового окна.
        -  name_box_offset_y (int) - вертикальный сдвиг поля имени в пикселях относительно текстового окна.
        - name_box_padding_x (int) - внутренние отступы поля имени по горизонтали.
        - name_box_padding_у (int) - внутренние отступы поля имени по вертикали.

2) Форматы внешних данных и ресурсов
Взаимодействие системы с внешней средой реализуется следующими форматами данных:
    1. Графические ресурсы (изображение фона и персонажей):
        - Поддерживаемые форматы файлов: PNG, JPG, JPEG, BMP, GIF
        - Способ обработки: Пути к файлам хранятся в виде строковых путей (background_path, image_path).
    2. Интерфейсные структуры:
        - Формат: XML- структура .ui, создаваемая в среде визуального проектирования Qt Designer.
        - Способ обработки: Загружается динамически на этапе инициализации главного окна с помощью метода uic.loadUi(), связывая визуальные элементы управления с логикой класса EditorWindow.

3) Механизмы отрисовки сцены
Сцена отображается послойно. Каждый слой рисуется в методе paintEvent в следующем порядке:
    1. Слой фона. Изображение фона масштабируется под размер виджета с сохранением пропорций и центрируется. Возвращается прямоугольник scene_rect, соответствующий реальным границам фона.
    2. Слой персонажа. Изображение персонажа масштабируется по высоте до 80% от высоты фона. Положение изображение персонажа при добавлении - это центр нижней границы изображения фона.
    3. Слой текста. Добавляется на сцену только если frame.text_visible == True. После этого на сцену добавляются:
        - фон текстового окна;
        - фон имени персонажа(если задано поле speaker);
        - текст реплики;
        - рамка выделения, если активет инструмент перемещения Tool.MOVE_TEXT.
