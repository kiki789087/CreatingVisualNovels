Техническое задание

Требования к функциональным характеристикам
---------------------------------------------

В программном продукте должен быть представлен один пользователь.В разрабатываемом программном продукте для пользователя должны быть реализованы следующие функциональные требования.

1.1 Управление кадрами
-----------------------
-**Список кадров.** Приложение должно предоставлять список кадров проекта. Пользователь должен иметь возможность выбрать кадр из списка для просмотра и редактирования.
-**Добавление кадра.** Приложение должно предоставлять кнопку добавления кадра. При добавлении кадра он добавляется в конец списка. При создании нового кадра фон и настройки текстового поля копируются из предыдущего кадра.
-**Удаление кадра.** Приложение должно предоставлять кнопку удаления кадра. Перед удалением приложение запрашивает у пользователя подтверждение, после подтверждения кадр удаляется.
-**Автоматическое название кадра.** Приложение должно автоматически присваивать каждому новому кадру название вида "Кадр N".
-**Переименование кадра.** Приложение предоставляет поле для изменения названия кадра. Название, заданное пользователем, не должно изменяться при перенумерации.
-**Перенумерация кадра.** Приложение должно автоматически пересчитывать номера в названиях кадров после добавления или удаления кадра.
-**Переход между кадрами.** Приложение должно предоставлять кнопки "Назад" и "Вперед" для последовательного перехода между кадрами в редакторе.

1.2 Редактирование сцены
-------------------------
-**Загрузка фона.** Приложение должно позволять пользователю загружать изображения фона для кадра из файла (форматы: PNG, JPG, JPEG, BMP, GIF)
-**Удаление фона.** Приложение должно предоставлять пользователю возможность удаления фонового изображения у текущего кадра.
-**Автоматическое взятие фона из предыдущего кадра.** Приложение должно автоматически брать фон из предыдущего кадра при создании нового и менять его, не изменяя фон предыдущего кадра.
-**Загрузка изображения персонажа.** Приложение должно позволять пользователю загружать изображение персонажа для кадра из файла (форматы: PNG, JPG, JPEG, BMP, GIF).
-**Удаление изображения персонажа.** Приложение должно предоставлять пользователю возможность удаления изображения персонажа у текущего кадра.
-**Перемещение персонажа.** Приложение должно позволять пользователю менять положение персонажа и сохранять его новое положение.
-**Послойное отображение сцены.** Приложение должно отображать сцену кадра в виде слоев: нижний слой - фон, верхний слой - персонаж.
-**Позиционирование персонажа.** При добавлении персонажа приложение автоматически размещает изображение по центру нижней границы фона. При этом пользователь может изменить его положение.

1.3 Управление текстовым полем
---------------------
-**Ввод текста.** Приложение должно предоставить поле для ввода текста реплики и имени говорящего персонажа.
-**Управление видимостью текстового поля.** Приложение должно предоставить кнопки "Добавить текст" и "Скрыть текст".
-**Настройки шрифта.** Приложение должно предоставить пользователю возможность выбрать шрифт из списка и задать размер шрифта.
-**Настройка цвета.** Приложение должно предоставить пользователю возможность задавать цвет текста, цвет имени персонажа и цвет фона текстового поля с помощью диалога выбора цвета.
-**Настройка фона текстового окна.** Приложение должно предоставить пользователю возможность регулировать ширину, высоту и прозрачность текстового поля.
-**Отображение имени персонажа.** Приложение должно отображать имя персонажа на отдельном поле, расположенном над основным текстовым окном. Цвет и прозрачность фона должны совпадать с фоном основного текстового поля.

1.4 Режим запуска
----------------------
-**Запуск приложения.** Приложение должно предоставлять кнопку запуска приложения для проверки работы кадров.
-**Линейная смена кадров.** В режиме запуска программы, кадры должны меняться линейно по щелчку мышки.
-**Завершение просмотра.** Приложение должно закрывать окно запуска по щелчку мыши на последнем кадре, а также по нажатию клавиши Esc в любой момент просмотра.

1.5 Инструменты управления
--------------------------------
-**Инструмент "Перемещение".** Приложение должно предоставить пользователю инструмент для перемещения изображения персонажа.
-**Инструмент "Перемещение текста".** Приложение должно предоставить пользователю инструмент для перемещения текстового поля в пределах фонового изображения.
-**Сохранение позиции.** Приложение должно сохранять новые координаты персонажа или текстового окна после изменения положения с помощью инструмента "Перемещение".
-**Ограничение позиции.** Приложение не должно позволять персонажу или текстовому полю выходить за пределы фонового изображения.


Описание действий пользователя:
-----------------------------------

Добавление кадра
  **Элемент интерфейса:** кнопка "Добавить кадр".
  **Описание команды:** в конец списка добавляется пустой кадр с названием "Кадр N". Кадр становится текущим, активируются поля редактирования, фокус переходит на поле названия.

Удаление кадра
  **Элемент интерфейса:** кнопка "Удалить кадр".
  **Описание команды:** выводится запрос подтверждения. При согласии кадр удаляется, автоматические названия перенумеровываются, текущим становится ближайший кадр. При отказе проект не изменяется.

Выбор кадра
  **Элемент интерфейса:** список кадров.
  **Описание команды:** выбранный кадр становится текущим. В полях отображаются его название и текст, на сцене показываются фон и персонаж.

Переименование кадра
  **Элемент интерфейса:** поле названия кадра.
  **Описание команды:** введённое название сохраняется как пользовательское и обновляется в списке. Оно не изменяется при перенумерации.

Переход к предыдущему кадру
  **Элемент интерфейса:** кнопка "Назад".
  **Описание команды:** текущим становится предыдущий кадр. На первом кадре кнопка недоступна.

Переход к следующему кадру
  **Элемент интерфейса:** кнопка "Вперёд".
  **Описание команды:** текущим становится следующий кадр. На последнем кадре кнопка недоступна.

Загрузка фона
  **Элемент интерфейса:** кнопка "Загрузить фон...".
  **Описание команды:** открывается диалог выбора файла (PNG, JPG, JPEG, BMP, GIF). После выбора фон отображается на сцене. При отмене фон не изменяется.

Удаление фона
  **Элемент интерфейса:** кнопка "Удалить фон".
  **Описание команды:** изображение фона удаляется из кадра, на сцене отображается надпись "Фон не загружен".

Загрузка персонажа
    **Элемент интерфейса:** кнопка "Загрузить персонажа...".
    **Описание команды:** открывается диалог выбора файла. После выбора персонаж отображается поверх фона по центру, нижним краем на нижней границе фона.

Удаление персонажа
    **Элемент интерфейса:** кнопка "Удалить персонажа".
    **Описание команды:** изображение персонажа удаляется из кадра.

Перемещение персонажа
    **Элемент интерфейса:** кнопка "Перемещение".
    **Описание команды:** при нажатии на кнопку пользователь может передвигать изовражение персонажа в пределах фонового изображения.

Перемещение текста
    **Элемент интерфейса:** кнопка "Перемещение текста".
    **Описание команды:** при нажатии на кнопку пользователь может передвигать текстовое окно в пределах фонового изображения.

Добавление текста
    **Элемент интерфейса:** кнопка "Добавить текст"
    **Описание команды:** показывает текстовое поле на сцене.

Скрытие текста
    **Элемент интерфейса:** кнопка "Скрыть текст"
    **Описание команды:** скрывает текстовое поле на сцене.

Запуск приложения
    **Элемент интерфейса:** кнопка "Запустить".
    **Описание команды:** открывается полноэкранное окно с первым кадром. Если кадров нет, выводится сообщение "Сначала добавьте хотя бы один кадр".

Завершение просмотра
     **Элемент интерфейса:** щелчок мышью на последнем кадре.
     **Описание команды:** окно запуска закрывается, пользователь возвращается в редактор.

Досрочный выход из просмотра программы
     **Элемент интерфейса:** клавиша Esc.
     **Описание команды:** окно запуска закрывается в любой момент просмотра.
